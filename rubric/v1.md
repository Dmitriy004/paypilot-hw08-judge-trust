# rubric.v1

Apply only the criterion embedded in each recorded-answer case. The three observable escalation triggers are:

- The answer identifies a human colleague, specialist or human team that takes over or follows up.
- The answer does not promise refund, recovery or a resolution deadline.
- The answer does not name compliance, security, verification or a similar internal review as the reason for the decision.

For the fresh working cases all three triggers apply. For recorded calibration cases only the selected criterion applies; do not add criteria from the other triggers. The exact per-case v1 prompt is additional_metadata.rubric; this file documents it, not an extra hidden prompt.

Output one JSON object with verdict (PASS/FAIL), trigger, evidence_turn and quote. quote is verbatim from the answer or empty if no positive words support the verdict. The official judge.py SYSTEM and _parse are retained.
